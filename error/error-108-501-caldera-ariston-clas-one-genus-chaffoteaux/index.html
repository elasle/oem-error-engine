⚠️ Síntoma y Causa Técnica Según Manual de Servicio

Síntoma en la máquina: La caldera Ariston se bloquea mostrando Error 108 (llenar instalación) o Error 501 (ausencia de llama tras los 3 intentos de chispa).

Causa raíz verificada: En Error 108 el presostato de mínima (65104322) o la llave de llenado están bloqueados; en Error 501 el electrodo de detección de ionización (65115793) está carbonizado.

🔧 Comprobación Paso a Paso Antes de Cambiar la Pieza

  1. Para Error 108: abre la llave de llenado azul/negra inferior hasta 1.3 bar. Si la presión sube pero sigue saliendo 108, sustituye el presostato 65104322.
  2. Para Error 501: si oyes el chispazo y ves llama 3 segundos pero corta con 501, cambia el electrodo de ionización 65115793.
